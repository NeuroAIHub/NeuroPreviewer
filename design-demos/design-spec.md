# NeuroPreviewer interactive workbench design specification

NeuroPreviewer 应从「对话工具结果里的一张静态图」升级成 DSH 内可以独立打开的神经科学数据预览工作台。主要用户是需要快速检查本地 MRI、fMRI 和未来 EEG/NWB 数据的科研人员、开发者与 AI Agent 使用者。他们进入预览器后应能从界面直接选择文件，文件 Header 解析完成后立即显示预览，不要求先发送一轮对话。对话入口仍然保留：Agent 调用 `neuro_preview` 时应打开或复用同一个预览工作台，而不是产生另一套交互逻辑。

三个方向统一使用桌面端 1440×900 画布，并包含真实 MRI 内容。必须出现的功能包括：文件名与维度信息、axial/coronal/sagittal 空间导航、X/Y/Z 坐标或切片滑块、第四维 volume/time 滑块、播放/暂停、上一帧/下一帧、当前强度与窗宽窗位信息、加载状态、非临床用途提示。所有空间控件必须共享一个十字光标状态，任何切面上的点击或滚轮都更新其他切面。时间控制只改变第四维，不改变空间位置。原型的交互可以使用预生成的有限切片模拟，但 UI 必须让用户真实点击和拖动，而不是静态摆拍。

输出是三个互不换皮的单文件 HTML 原型和对应截图。方向一强调沉浸式单视图，方向二强调专业 MPR 三切面效率，方向三强调直接操控与时间曲线。三版功能事实一致，但信息层级、布局骨架与交互重心必须明显不同。视觉应像科研仪器而不是营销 Dashboard；避免装饰性卡片、无意义图标和炫技渐变。所有文本在 1440×900 截图中可读，正文不小于 14px，注释不小于 12px。原型仅用于方向选择，用户选定后才进入生产实现。
