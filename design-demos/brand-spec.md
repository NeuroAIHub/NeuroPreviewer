# NeuroPreviewer prototype brand specification

## Assets

- Product name: NeuroPreviewer.
- Package: `@brainpilot/dsh-neuro-previewer`.
- Host product: DeepSeek Harness (DSH).
- No official NeuroPreviewer logo asset exists in the repository. The prototypes use a restrained text wordmark and do not invent a symbol.
- DSH chrome is represented structurally without reproducing or inventing a DSH logo.
- Scientific imagery comes from the locally downloaded OpenNeuro `ds000005` fixtures and is used only as preview content.

## Colour source

- Neutral values derive from the existing DSH dark UI vocabulary and scientific image-viewer conventions.
- Accent values encode function: cyan for spatial position, amber for time/volume, and muted red only for errors or limits.
- Each direction is allowed a different neutral temperature, but controls retain the same semantic colours.

## Typography

- Interface text: system UI sans-serif for compatibility with DSH.
- Coordinates and dimensions: monospace, with tabular numerals.
- No decorative display font; the viewer is an instrument rather than a marketing surface.

## Prohibitions

- No fabricated medical diagnosis, patient identity, or clinical claim.
- No ornamental neuroscience icons or invented brain logo.
- No generic purple SaaS gradient, glass cards, or decorative statistics.
- The interface must state that voxel orientation is not yet anatomically reoriented.
